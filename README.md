## `01` — About

I build practical software at the intersection of **full-stack development, workflow automation, and local AI**.

The goal is not to add AI everywhere. The goal is to find a repetitive workflow or a real product problem, then build the smallest reliable system that solves it.

```text
BUILD      Web products, APIs, real-time systems and internal tools
AUTOMATE   Repetitive workflows using n8n, Python and LLMs
DEPLOY     Self-hosted services using Linux, Docker, PM2 and systemd
LEARN      Java DSA, system design and open-source collaboration
SHARE      Architecture, mistakes, trade-offs and lessons as tomxdev
```
